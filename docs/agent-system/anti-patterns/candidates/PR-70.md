## `AP-R70-001` — Evidence maturity and promotion collapsed into one lifecycle
- **Source evidence:** reviewed head `d4d4ce22d827e49b948994488c83e943c130f1f0`; review `PRR_kwDOTeqfeM8AAAABMPflrw`; thread `PRRT_kwDOTeqfeM6fZk5b`; comment `3936795340`.
- **Observed behavior:** the anti-pattern README showed `VALIDATED_LOCAL → PROMOTED_AREA / PROMOTED_COMMON` as one linear state chain.
- **Why reasonable:** both values describe a lesson's lifecycle and were easy to draw as one progression.
- **Actual failure:** promotion overwrote evidence maturity even though the schema modeled `evidence_state` and `promotion_state` independently.
- **Repair:** represent evidence maturity and promotion as orthogonal axes.
- **Guard:** examples must allow combinations such as `VALIDATED_LOCAL + NONE` and `VALIDATED_LOCAL + PROMOTED_COMMON`.
- **Evidence state:** `CONFIRMED`.
- **Promotion state:** `NONE`.

## `AP-R70-002` — Seeded lesson prose without immutable source edges
- **Source evidence:** reviewed head `d4d4ce22d827e49b948994488c83e943c130f1f0`; review `PRR_kwDOTeqfeM8AAAABMPflrw`; thread `PRRT_kwDOTeqfeM6fZk5f`; comment `3936795346`.

- **Why reasonable:** the PR number was sufficient for human navigation during the active conversation.
- **Actual failure:** later agents could not mechanically/auditably distinguish which immutable candidate and finding established each lesson in a multi-head PR.

- **Promotion state:** `NONE`.
