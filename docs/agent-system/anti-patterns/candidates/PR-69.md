## `AP-R69-001` — Regex proves nearby text instead of the actual binding

- **Observed behavior:** a regression could find the desired head-SHA expression near an `actions/checkout` occurrence without proving that expression was the checkout step's `with.ref`.
- **Why reasonable:** text matching looked like a lightweight structural assertion.
- **Actual failure:** unrelated nearby YAML could satisfy the test while checkout silently regressed.
- **Repair:** locate the named checkout step, verify the action, resolve that step's `with` mapping, then assert the exact `ref` value.
- **Guard:** mutate only checkout `with.ref`; the test must fail even if the desired SHA expression remains elsewhere nearby.
- **Promotion:** `NONE` at bootstrap. Promote only if recurrence/generalization justifies a test-structure rule.
